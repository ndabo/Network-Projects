# Network Design Projects (Cisco Packet Tracer)

This repository contains network design projects created using Cisco Packet Tracer.
The goal of these projects is to demonstrate practical networking concepts such as network topology design, IP addressing, routing, switching, and basic network services.

## Project Overview

These projects simulate real-world network infrastructures and are designed to showcase how different network components interact in a structured environment.

The designs include:

* Routers
* Switches
* End devices (PCs, printers, phones)
* Servers
* Network services configuration

## Networking Concepts Demonstrated

Some of the networking concepts implemented in these projects include:

* Network topology design
* Subnetting and IP addressing
* VLAN configuration
* Routing between networks
* DHCP configuration
* DNS configuration
* HTTP and Email server configuration
* Basic network troubleshooting

## Tools Used

* Cisco Packet Tracer
* Networking concepts based on Cisco networking principles

## How to Use

1. Download the `.pkt` project file from the repository.
2. Open the file using Cisco Packet Tracer.
3. Explore the network topology and device configurations.
